# 隐私请求处理说明

适用于 KTV Assistant 个人项目运营者。公开邮箱见 `src/content/publicPages.ts`，不公开法定姓名。此说明不是自动邮件服务，不会代运营者发送任何邮件或执行生产删除。

## 收件与回复

通常三天内查看并回复。确认收件不等于请求已办结；适用法定期限需要单独遵守，不能以“三天内回复过邮件”代替。记录接收日期、请求类型、核实步骤、处理范围与结果；不要把原始请求、邮箱或个人资料提交到 Git。仅保留处理所必需的信息，办结后清理不再需要的副本。

可以使用以下确认模板（按实际情况修改，不自动发送）：

> 我们已收到你的隐私请求。为帮助定位，请提供房间编号或链接、约略使用时间，以及希望查询、更正或删除的内容。请勿发送密码、身份证件或其他不必要的敏感信息。我们会核实请求涉及的范围，再说明后续处理方式；房间链接本身不能证明你有权获取其他参与者的信息。

## 核实和定位

1. 区分浏览器本地数据、共享房间数据、搜索使用事件、公共查询/歌曲资料及第三方数据。
2. 仅使用为定位所必要的房间编号和时间信息；不要求用户提交身份证或 YouTube 密码。若无法核实所请求记录与请求者的关系，说明限制，不披露其他人的操作或个人资料。
3. 房间 URL 是共享入口，不是个人账号或房主身份凭据。系统没有可证明“某条搜索属于某个人”的登录账号，不向请求者声称能导出其完整个人历史。
4. `rooms` / `queue_items` / `playback_states` / `playback_events` 使用 `room_id` 关联；`search_events.room_id` 可以关联房间，但同一房间的操作可能来自多人。
5. 公共 D1 repository / catalog 和 KV 是独立资料；不能仅因删除一条使用事件，就声称其搜索词和视频资料在所有层都消失。

## 按数据类型处理

| 类型 | 实际可执行的处理与限制 |
| --- | --- |
| 浏览器语言、设备标识、房间快照、搜索 UI、政策确认 | 用户可清除此站点浏览器数据。房间政策菜单的撤回按钮会停止该页功能并清除确认记录；清除本地数据不等于删除服务端数据。存储被浏览器阻止时，仅保证当前页面的内存选择。 |
| 公开查询资料含个人信息 | 在管理员资料库中定位准确条目，先预览，确认范围后使用既有删除入口；其实现会处理对应 D1 entry 与 KV key。catalog 或其他查询条目可能另有副本，需工程侧核查，不承诺一次点击清除所有副本。 |
| 房间及其事件 | 常规期限为事件 30 天、停用且 30 天未更新的房间 30 天。涉及整房间提前删除，先确认对所有参与者的影响，安排设备退出并由工程侧提出定向事务方案，再取得针对实际范围的执行授权。当前没有公开的“一键删除所有个人历史”接口。 |
| 管理员审计与日配额 | 常规保留 90 天；若涉及请求者个人信息或适用保留义务，单独核查，不能机械地认为 90 天总是合适。 |
| Cloudflare 备份和 Google/YouTube 内容 | 按服务提供方实际规则处理。不能把主数据库删除或清除浏览器存储表述成第三方记录/备份立即消失。 |

普通 debug `/cleanup` 只清理完成/移除的队列项，**不是整房间隐私删除**，不可用于证明请求已经全部完成。停用房间的常规清理是有限批次任务，积压或故障可造成延迟，需检查任务日志和真实查询结果。

## 办结核对

- 使用只读查询确认实际处理范围，分别检查房间记录、事件与敏感查询资料。不要仅凭 HTTP 200 或按钮消失就回复“全部删除”。
- 回复实际完成的内容、尚存的共享数据/备份限制，以及无法核实或需要继续处理的部分。
- 保留最小处理记录；邮件请求不进入公开站点、分析日志或代码仓库。
